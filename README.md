# BookNest Library Catalogue

## Overview

BookNest is a responsive static library catalogue that allows users to browse a collection of books, search by title or author, filter books by category, view availability status, mark books as favorites, and preserve favorite selections using browser localStorage.

## Features

* Browse a library catalogue
* Search books by title or author
* Filter books by category
* Available and Borrowed status indicators
* Add and remove favorites
* Persistent favorites using localStorage
* No-results feedback for searches and filters
* Responsive desktop, tablet, and mobile interface
